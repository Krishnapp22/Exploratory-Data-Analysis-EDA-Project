# Titanic Dataset - Exploratory Data Analysis

This project performs **Exploratory Data Analysis (EDA)** on the Titanic dataset using Python.

## 📌 Objectives

* Analyze the dataset using statistical summaries.
* Handle missing values.
* Identify survival patterns.
* Analyze relationships between gender, passenger class, age, and survival.
* Visualize important trends and correlations.

## 🛠️ Technologies

* Python
* Pandas
* NumPy
* Matplotlib

## 📊 Key Analysis

* Survival rate
* Survival by gender
* Survival by passenger class
* Age distribution
* Fare distribution
* Correlation analysis

## 🚀 Outcome

The project helps identify important patterns in the Titanic dataset and demonstrates fundamental **data analysis and visualization skills**.
